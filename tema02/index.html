Motores de los navegadores

Muchos navegadores utilizan tecnologías de Chromium y comparten el motor de renderizado Blink. Chrome, Edge y Opera utilizan este motor, por lo que pueden tener un comportamiento parecido en muchas páginas. Firefox utiliza Gecko y Safari utiliza WebKit, por lo que existen diferencias entre los motores. Para un desarrollador esto significa que una página no debe probarse solamente en un navegador. Una característica de HTML, CSS o JavaScript puede comportarse de forma diferente dependiendo del navegador y de su versión.

Ejemplo de compatibilidad

CSS Subgrid

CSS Subgrid permite que una cuadrícula hija utilice las filas o columnas definidas por la cuadrícula de su elemento padre.

Esta característica no tuvo el mismo nivel de compatibilidad en todas las versiones de los navegadores. Por ejemplo, las versiones antiguas de Chrome, Edge, Firefox, Safari y Opera no ofrecían el mismo soporte.

Reflexión

Si un cliente me encargara una página web, primero la probaría en Chrome y Firefox porque utilizan motores diferentes. También comprobaría la página en un dispositivo móvil para asegurarme de que el diseño se adapta correctamente a pantallas pequeñas. Además, probaría Safari si la web está destinada a usuarios de dispositivos Apple.
